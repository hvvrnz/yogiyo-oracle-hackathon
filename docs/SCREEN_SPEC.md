# 역할별 화면 명세

## 고객 화면

- 예상 도착시간 범위와 마지막 갱신 시각
- 주문 접수·조리·픽업·배달 진행 단계
- 조리 완료 편차, 경로 중복률, 가방 체류시간
- 비식별 경로 지도와 라이더 위치
- 음식 품질 제한과 남은 여유
- 날씨에 따른 이동 지연 안내
- AI 추천 사유 바텀시트

## 사장님 화면

- 매장 영업·혼잡 상태와 주문 집계
- 주문별 메뉴, 접수시각, 결제금액
- AI 예상 조리시간과 목표 완료시각
- 조리 시작 권장 문구와 예측 신뢰도
- 라이더 도착시각·거리·예상 대기시간
- 주문 수락·조리 시작·5/10분 지연·조리 완료
- 패키지 조리 완료 편차와 동기화 목적
- 경로 재계산 결과

## 라이더 화면

- 패키지 건수·총 수익·시간당 환산 수익
- 예상 소요시간·총 거리·추가 거리·매장 대기
- 품질·ETA 가드레일 통과 여부
- 매장별 조리 준비 상태
- 픽업과 배달이 섞인 전체 방문 순서
- 배차 수락·거절과 현재 단계 완료
- 배차 수락 전 고객 상세주소 보호
- 날씨와 안전 운행 정보

## 시연 제어 화면

- 세 역할 화면 동시 표시
- 라이더 수락, 매장 지연, 신규 주문, 날씨 변경
- 라이더 위치 자동 이동 시작·정지
- 다음 픽업·배달 단계 진행
- 전체 상태 초기화
- 실시간 이벤트 로그
