# 데이터 계약

## 핵심 엔터티

- `Store`: 음식점명, 업종, 주소, 위경도, 기본 조리시간, 보정계수, 혼잡도
- `Order`: 고객·매장 연결, 메뉴, 상태, 조리 예측, 고객 ETA, 품질 제한
- `Rider`: 상태, 위치, 위치 갱신시각, 수행 패키지
- `DeliveryPackage`: 최대 3개 주문, 효율 지표, 가드레일, 선택 경로
- `RouteStep`: 픽업/배달 유형, 주문, 목적지, 순서, ETA, 거리, 시간, 상태
- `Event`: 이벤트 ID, 버전, 유형, 시각, 관련 엔터티

## 데이터 출처

### 공공데이터/API

- 음식점 이름·업종·주소·위경도: 공공데이터포털
- 구간별 도로 거리·시간·경로: 카카오모빌리티 길찾기 API
- 강수·기온·풍속·예보: 기상청 API

### 더미 데이터

- 랜덤 시간의 주문 발생
- 고객 주소 좌표
- 라이더 초기 위치와 경로 이동
- 매장·메뉴별 기본 조리시간
- 실제 조리 완료 및 지연 이벤트
- 배달비와 라이더 수익

### 내부 계산

- 조리 완료 예상시각과 편차
- 라이더 매장 도착 ETA와 매장 대기시간
- 고객별 도착 ETA 범위
- 음식 방치·가방 체류시간
- 경로 중복률과 추가 이동거리
- 90개 유효 경로 중 최적 순서
- 시간당 환산 수익
- 품질·ETA 가드레일 통과 여부
